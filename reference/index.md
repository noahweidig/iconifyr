# Package index

## Get icons

Fetch icons as SVG, files, inline HTML or PNG.

- [`iconify_get()`](https://noahweidig.github.io/iconifyr/reference/iconify_get.md)
  : Get an icon as SVG
- [`iconify_download()`](https://noahweidig.github.io/iconifyr/reference/iconify_download.md)
  : Download icons as SVG files
- [`iconify_html()`](https://noahweidig.github.io/iconifyr/reference/iconify_html.md)
  : Inline an icon as HTML
- [`iconify_png()`](https://noahweidig.github.io/iconifyr/reference/iconify_png.md)
  : Render an icon to PNG

## Search and browse

Find icons and list icon sets.

- [`iconify_search()`](https://noahweidig.github.io/iconifyr/reference/iconify_search.md)
  : Search for icons
- [`iconify_sets()`](https://noahweidig.github.io/iconifyr/reference/iconify_sets.md)
  : List icon sets
- [`iconify_icons()`](https://noahweidig.github.io/iconifyr/reference/iconify_icons.md)
  : List the icons in a set

## Licensing

Check licenses and attribution requirements.

- [`iconify_license()`](https://noahweidig.github.io/iconifyr/reference/iconify_license.md)
  : Get license and author information

## Utilities

- [`iconify_cache_clear()`](https://noahweidig.github.io/iconifyr/reference/iconify_cache_clear.md)
  : Clear the iconifyr cache
